Antes de conectar nada

Conoce tu placa

El ESP32 DevKit es una placa con un microcontrolador de dos núcleos, WiFi y Bluetooth integrados. Toca cada parte para ver para qué sirve.

Idea principal

El ESP32 trabaja a 3,3 V. Nunca le metas 5 V por un pin de entrada.

Una sola vez

Instala el soporte en Arduino IDE

  1. Instala Arduino IDE 2Descárgalo de arduino.cc e instálalo como cualquier programa.
  2. Agrega la URL de EspressifVe a Archivo → Preferencias y en "URLs adicionales del gestor de placas" pega: 
    https://espressif.github.io/arduino-esp32/package_esp32_index.json
  3. Instala las placasAbre el Gestor de placas (icono de la placa en la barra izquierda), busca esp32 e instala esp32 by Espressif Systems. Tarda unos minutos.
  4. Elige tu placa y el puertoEn Herramientas → Placa elige ESP32 Dev Module. Conecta el cable y en Herramientas → Puerto elige el que apareció (COM3, COM4… en Windows; /dev/ttyUSB0 en Linux).
¿No aparece ningún puerto?

Revisa el chip USB de tu placa (está cerca del conector): si dice CP2102 instala el driver CP210x de Silicon Labs; si dice CH340, el driver CH34x. Y prueba otro cable: muchos cables solo cargan y no transmiten datos.

Hola mundo

Haz parpadear el LED

Todo programa de Arduino tiene dos partes: setup() se ejecuta una vez al encender y loop() se repite para siempre.

Mueve el control para cambiar la pausa: el código y el LED cambian juntos.

void setup() {
  pinMode(2, OUTPUT);   // el pin 2 será salida
}

void loop() {
  digitalWrite(2, HIGH);  // enciende
  delay(500);
  digitalWrite(2, LOW);   // apaga
  delay(500);
}
Para subirlo

Pulsa la flecha → Subir. Si se queda en Connecting....____, mantén presionado BOOT hasta que empiece a escribir porcentajes y suéltalo. Luego pulsa EN si no arranca solo.

Lo que lo hace especial

Conéctate a tu red WiFi

#include <WiFi.h>

const char* red   = "MiRed";
const char* clave = "mi-clave";

void setup() {
  Serial.begin(115200);
  WiFi.begin(red, clave);
  Serial.print("Conectando a "); Serial.print(red);
  while (WiFi.status() != WL_CONNECTED) {
    delay(300); Serial.print(".");
  }
  Serial.println(); Serial.print("¡Conectado! IP: ");
  Serial.println(WiFi.localIP());
}

void loop() {}

Solo redes de 2,4 GHz

El ESP32 no ve redes de 5 GHz. Si tu router tiene las dos con el mismo nombre y no conecta, crea una red de 2,4 GHz aparte.

Para no quemar nada

Los pines que debes conocer

PinesQué pasaConsejo
GPIO 6 a 11Están conectados a la memoria flash interna.No los uses nunca.
GPIO 0, 2, 12, 15Son pines de arranque (strapping): su nivel al encender decide cómo arranca.Evita conectarles cosas que los fuercen al encender.
GPIO 34 a 39Solo entrada, sin resistencia pull-up interna.Perfectos para leer sensores analógicos.
ADC2 (GPIO 0, 2, 4, 12–15, 25–27)No funcionan como analógicos mientras el WiFi está activo.Con WiFi, lee analógico en ADC1 (GPIO 32–39).
TodosLógica de 3,3 V. Corriente recomendada ≈ 20 mA por pin.Para relés o motores usa un transistor.

Diagnóstico

Errores comunes

"Failed to connect to ESP32"

Mantén BOOT presionado al empezar la subida. Si pasa siempre, pon un condensador de 10 µF entre EN y GND.

El monitor muestra símbolos raros

La velocidad del monitor no coincide con Serial.begin(). Ponla en 115200.

Se reinicia solo con el WiFi

Picos de consumo de hasta 300 mA: el puerto USB o el cable no alcanzan. Usa otro puerto, un cable corto o una fuente externa.

El LED de la placa no parpadea

Algunas placas tienen el LED en otro pin o no lo traen. Conecta un LED con su resistencia de 220 Ω al GPIO 2.
